# 市場トレンドフィルター 検証記録（不採用）

---

# 結論

**検証の結果、効果が確認できなかったため不採用とした。** 実装（`rules/entry_rule.py`の
`market_direction`引数、`backtest/simulator.py`の`market_order_by_date`引数）は削除済み。
同じ着想を再度試す前に、この記録を確認すること。

---

# 1. 背景・仮説

ショートのバックテスト（10銘柄×最大10年、2回実施）で、いずれも平均リターンが
マイナス（-0.47%〜-0.62%）だった。年別に見ると、市場全体が実際に下落した
2020年（コロナショック）だけ成績が良く（勝率61%、+2.07%）、それ以外の年は
軒並み悪かった。これは検証銘柄が長期的に強い上昇トレンドの大型株ばかりだった
ため、個別銘柄の短期下降シグナルの多くが「大きな上昇トレンドの中の一時的な
調整」に過ぎなかったことが原因ではないか、という仮説を立てた。

そこで、日経平均（`^N225`）のMA5/20/60並び順が"short"（下降トレンド）の日
だけショートを候補にするフィルターを実装し、検証した。

---

# 2. 検証結果

10銘柄・10年分の日足ショートで比較（利確・損切ルールは全パターン共通の
最終仕様「利確は遠い方・損切は近い方」）。

| | フィルター無し | フィルターのみ |
|---|---|---|
| トレード数 | 247 | 87 |
| 勝率 | 34.4% | 28.7% |
| 平均リターン | **-0.47%** | **-1.25%** |
| 平均勝ち/負け | +4.50%/-3.07% | +5.51%/-3.98% |

**フィルターを適用すると、勝率・平均リターンともに悪化した。** 2020年単年の
アネクドートに基づく仮説だったが、他の期間まで含めて検証すると裏付けられなかった。

---

# 3. 考えられる理由（未検証の仮説）

- 2020年のコロナショックは急落・急変動が特徴的な特殊な年で、「MA5<20<60が
  揃った下降トレンド」という機械的な定義には必ずしも当てはまらない値動きだった
  可能性がある
- 日経平均自体が「下降トレンド」と判定される局面は、値動きが荒くだましが
  多い時期（下落の初動や、下落の最終局面での乱高下）である可能性があり、
  個別銘柄の損切りが増えやすかったと考えられる
- 大型株は「押し目買い」が入りやすい銘柄が多く、市場全体が崩れている時ほど
  「下がったら買う」という逆張り資金が強く働き、ショートの損切りを誘発しやすい
  のかもしれない

---
