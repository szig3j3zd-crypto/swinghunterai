# ダッシュボード仕様書（Streamlit UI）

---

# 1. 概要

`ui/dashboard.py`（`streamlit run ui/dashboard.py` で起動）。

「今日の売買候補を見る」「個別銘柄を調べる」「売買記録・監視銘柄を管理する」の3つを
1つの画面で行えるようにしたダッシュボード。サイドバーの設定は全タブ共通。

画面構成:

- サイドバー: 個別銘柄検索・方向・時間足・採用指数・フィルタ・スキャン実行ボタン
- メイン: 「スキャン」「売買銘柄」「監視銘柄」の3タブ

---

# 2. サイドバー

## 2.1 個別銘柄検索

`st.selectbox`（"コード 銘柄名" 形式のラベルで部分一致検索）で、東証プライム・
スタンダード・グロースの全アクティブ銘柄から1件選べる。選択すると、スキャン結果の
有無に関わらずその銘柄の判定結果とチャートを表示する（4章）。

## 2.2 方向・時間足

- 方向: ロング（買い） / ショート（売り）
- 時間足: 日足 / 週足（週足は`indicators/resample.py`で日足データをリサンプルして判定）

## 2.3 採用指数（対象銘柄の絞り込み）

`st.multiselect`。複数選択すると、選択した指数の銘柄を**和集合**（コード重複除去）で
まとめて対象にする。デフォルトは未選択で、1つも選択せずにスキャンを実行すると
エラーメッセージを表示して中断する。

| 選択肢 | 実装（`service/screening_service.py`） |
|---|---|
| 東証プライム全体 | `get_prime_stocks()` |
| 日経225 | `get_nikkei225_stocks()`（`stock_master.nikkei225`列） |
| JPX日経400 | `get_jpx400_stocks()`（`stock_master.jpx400`列） |

日経225・JPX400のデータは`scripts/update_stock_master.py`が
`data/stock_data/master/{nikkei225,jpx400}.csv`を読み込んでDBへ反映する
（nikkei225.csvはヘッダー無し・1列のコード一覧形式）。

## 2.4 フィルタ

出来高・株価（下限/上限）・時価総額（下限）を任意に変更できる。すべて「0で無効」。

- 出来高・株価フィルタは`rules/screening_filters.py`、エントリー判定
  （`rules/entry_rule.py` の `evaluate_entry`）内で適用される
- 時価総額フィルタは、DBに時価総額を保存していないため、**他の条件を通過した
  候補にのみ**Yahoo Finance（`data/market_cap_reader.py`）へライブ問い合わせして
  絞り込む（`service/screening_service.py` の `_filter_by_market_cap`）。全銘柄には
  適用しないため、スキャン全体の速度への影響は小さい

「0で無効」の実現方法: `None`を渡すとconfig既定値にフォールバックしてしまうため、
下限は`0`、上限は`float("inf")`という「フィルタ関数がそのまま『制約なし』と
解釈できる値」を明示的に渡す（`rules/screening_filters.py`参照）。

# 3. スキャンタブ

## 3.1 候補一覧

サイドバーの「候補を更新」を押すと、`service.screening_service.get_today_candidates()`
で選択中の採用指数・方向・時間足・フィルタに基づき候補を抽出し、スコア降順の表で
表示する（コード・銘柄名・スコア・判定理由・株価・損切価格・利確価格・
リスクリワード比）。

行は選択可能（`st.dataframe(..., on_select=..., selection_mode="single-row")`）。
行を選択すると、その銘柄の判定結果とチャートを4章の位置に表示する。

新しいスキャンを実行すると、選択状態・チャート表示はリセットされる
（`scan_version`をインクリメントし、候補一覧の`key`に含めることで
Streamlit側に新しいウィジェットとして扱わせる）。

## 3.2 売買銘柄・監視銘柄への追加

候補一覧の候補、または個別銘柄検索の結果（**エントリー候補かどうかを問わない**。
手動で売買記録・監視したいだけの場合もあるため）から銘柄を選び、

- 売買銘柄として追加: 取引日・購入株価（デフォルトは現在株価）・株数・決済株価
  （0のままなら未決済）を入力して登録
- 監視銘柄として追加: ボタン1つで登録（方向のみ引き継ぐ）

# 4. 個別銘柄検索・銘柄詳細（チャート）

個別銘柄検索、または候補一覧の行選択のどちらでフォーカスした銘柄でも、
同じ位置（候補一覧の直前）に同じ形式で結果を表示する
（`_render_focus_block`、`focus_mode`／`focus_candidate`セッション状態で管理）。

候補一覧を更新すると個別銘柄検索側のフォーカスは消え、逆に個別銘柄検索を
操作すると候補選択側のフォーカスに優先する（検索ボックスの`on_change`で
`focus_mode="search"`をセットし、候補一覧側は選択イベントのコールバックでのみ
`focus_mode="candidate"`を書き換える。単純に選択状態を毎回読み直す方式だと、
ウィジェットの選択状態が残り続けて他方の操作を上書きしてしまうため）。

## 4.1 判定結果

エントリー候補なら候補一覧と同じ形式の1行表、候補でなければ見送り理由
（`SKIP_REASON_LABELS`で日本語化）と現在の株価を表示する。

## 4.2 チャート（`ui/chart.py`）

`service.screening_service.get_stock_chart_data()`で取得したOHLCV＋移動平均
（sma5/20/60）をPlotlyのローソク足＋出来高サブプロットで表示する。

- 表示切替: ローソク足・5日線・20日線・60日線・出来高（チェックボックス）
- 表示期間: 1ヶ月・3ヶ月・6ヶ月・1〜10年（1年刻み）のプルダウン。
  デフォルトは日足=6ヶ月、週足=3年
- 選択期間のデータに合わせて、価格軸・出来高軸のレンジを自動でフィットさせる
  （`ui.chart.compute_visible_window`）。全期間分のレンジのまま表示すると
  ローソク足が潰れて見えなくなるため
- 色: 陽線=赤、陰線=青（日本の慣例）、5日線=黄、20日線=赤、60日線=青、
  出来高バーは陽線陰線を区別せず全て黄
- 高値・安値・始値・終値は、Streamlit要素ではなくPlotly側の注釈
  （`fig.add_annotation`）として凡例の右隣に埋め込む
- モードバーのアイコン説明は日本語化（`ui.chart.PLOTLY_JA_LOCALE`。Plotly公式の
  日本語ロケールファイルを読み込む手段が無いため、英語→日本語の対訳辞書を
  `config.locales`に直接渡している）
- モードバーの「直線を描画」で支持線・抵抗線を描画できる。描いた線はクリックで
  選択→端点ドラッグで編集、「選択した図形を削除」アイコンまたはDeleteキーで削除

### 既知の制限

- 手動でのドラッグズーム・描画した線は、**他の操作（チェックボックス切替等）で
  再読み込みされると消える**。Plotly標準の`uirevision`とStreamlitの`key`を
  組み合わせる方法を試したが、`st.plotly_chart`では効かなかった（Streamlit側の
  制限と考えられる）。表示期間はプルダウン操作のたびに綺麗にフィットするため
  実害は小さいが、完全に解決するには生JavaScriptイベントを扱うカスタム
  コンポーネントの開発が必要
- 手動ドラッグズームでは価格軸が自動フィットしない（表示期間プルダウンでの
  切り替えのみ自動フィット対象）

# 5. 売買銘柄タブ（トレード記録）

`database/trade_repository.py`（`trades`テーブル）で永続化。

- 年→月にグルーピングして表示（`service/trade_service.py`の
  `group_by_year_and_month`）。それぞれ月間損益・年間損益を表示し、
  全期間の損益合計も表示する
- 損益計算（`calculate_pnl`）: ロングは`(決済株価-購入株価)×株数`、
  ショートは`(購入株価-決済株価)×株数`。決済株価が無い（未決済）トレードは
  損益計算・集計の対象外
- 表内で購入株価・決済株価・株数を直接編集できる（`st.data_editor`）。
  決済株価を後から入力して未決済→決済済みに変更できる
- 削除は別途セレクトボックス+ボタンで行う

# 6. 監視銘柄タブ

`database/watchlist_repository.py`（`watchlist`テーブル）で永続化。
コード・銘柄名・方向・追加日の一覧表示と削除のみのシンプルな機能。

# 7. データモデル

## trades

| 列 | 内容 |
|---|---|
| id | 主キー |
| code, company_name, direction | 銘柄コード・銘柄名・方向（long/short） |
| trade_date | 取引日（"YYYY-MM-DD"） |
| entry_price, exit_price, quantity | 購入株価・決済株価（NULL=未決済）・株数 |
| created_at | 登録日時 |

## watchlist

| 列 | 内容 |
|---|---|
| id | 主キー |
| code, company_name, direction | 銘柄コード・銘柄名・方向 |
| added_date | 追加日（"YYYY-MM-DD"） |
| created_at | 登録日時 |

# 8. 実装ファイル一覧

| ファイル | 役割 |
|---|---|
| `ui/dashboard.py` | 画面本体 |
| `ui/chart.py` | チャート生成（Plotly） |
| `service/screening_service.py` | スキャン・個別銘柄評価・チャート用データ取得・採用指数別銘柄取得 |
| `service/trade_service.py` | 損益計算・年月グルーピング |
| `data/market_cap_reader.py` | 時価総額のライブ取得（Yahoo Finance） |
| `database/trade_repository.py` | 売買銘柄のCRUD |
| `database/watchlist_repository.py` | 監視銘柄のCRUD |
