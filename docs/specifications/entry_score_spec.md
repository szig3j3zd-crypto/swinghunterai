# 売買候補スコアリング仕様書（Ver2.3）

---

# 1. 目的

エントリー候補として抽出された銘柄を100点満点でランキング化し、
優先順位を付けられるようにする。

roadmap_master.md記載の初期版方針（MA+40 / 出来高+40 / リスク+20 = 100点）に沿う。

---

# 2. MAスコア（最大40点）

反発回数（`rules/bounce_count.py`が算出する`bounce_number`）を使う。
反発が浅い（1発目）ほど、支持線/抵抗線や20日線から離れておらず
上昇・下落余力が大きいとみなして高得点にする。

| 反発回数 | 点数 |
|----------|------|
| 1発目 | 40 |
| 2発目 | 20 |
| それ以外 | 0（本来はentry_rule側で候補から除外済み） |

---

# 3. 出来高スコア（最大40点）

出来高倍率（`indicators/volume.py`が算出する`volume_ratio` = 当日出来高 ÷ 出来高平均）を使う。
support_resistance_spec.md 9章の信頼度スコアと同じ考え方を踏襲する。

| 出来高倍率 | 点数 |
|------------|------|
| 2.0倍以上（急増） | 40 |
| 1.5倍以上 | 20 |
| それ未満 | 0 |

---

# 4. リスクスコア（最大20点）

リスクリワード比（`rules/exit_rule.py`が算出する`risk_reward_ratio`、目安2:1）を使う。

| リスクリワード比 | 点数 |
|-------------------|------|
| 2.0以上 | 20 |
| 1.0以上2.0未満 | 10 |
| 1.0未満 | 0 |

---

# 5. 合計スコア

MAスコア + 出来高スコア + リスクスコア（最大100点）

`rules/entry_rule.py`の`evaluate_entry`が、エントリー候補成立時の戻り値へ
`score`（`ma_score`/`volume_score`/`risk_score`/`total_score`を持つdict）として含める。

---

# 6. 未確定・将来課題

- 支持線・抵抗線の信頼度スコア（タッチ回数・期間・上位足一致、support_resistance_spec.md 9章）は、
  今回のスコアリングには組み込んでいない。パターンA（支持線/抵抗線付近の半分シグナル）でのみ
  意味を持つため、パターンB（20日線付近）と重み付けの整合性を取る必要があり、Ver3.0以降で検討する
- RS分析・市場分析・ローソク足分析などの将来追加指標をスコアへ組み込む方法は未検討
- 各点数のしきい値（40/20/0、2.0倍・1.5倍など）は初期案であり、バックテスト結果を見て調整する
