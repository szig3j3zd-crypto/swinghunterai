# スマホ・他PCからのアクセス（Tailscale）

---

# 概要

> **PCの電源が入っていない間もアクセスしたい場合はこの方式では不十分。
> [cloud_access.md](cloud_access.md) を参照。**
> 本ドキュメントの方式は、PCが起動している間だけ・自宅ネットワークの範囲を
> 超えて手早くアクセスしたい場合の軽量な選択肢として残している。

株探しダッシュボード（`ui/dashboard.py`）はPC上でStreamlitを起動して使う仕組みのため、
そのままでは同じPC（`localhost`）からしかアクセスできない。

[Tailscale](https://tailscale.com/) を使い、PCとスマホ・他のPCを同じ私設ネットワーク
（Tailnet）に参加させることで、外出先からでもPCで起動中のダッシュボードへ安全に
アクセスできるようにする。無料枠（個人利用なら台数上限に達しない）で完結する。

- 公開URLを発行する方式（Streamlit Community Cloud等）ではなく、自分のデバイス同士を
  つなぐ方式のため、株価DB（`data/stock.db`、約485MB）やトレード記録をクラウドへ
  移行する必要がない。既存のデータ取得・更新の仕組み（`update_prices.bat`等）も
  そのまま使える
- 前提として、**アクセスしたい間はPC側で株探しを起動しておく必要がある**
  （PCの電源が落ちている、またはStreamlitを起動していない間はスマホ側からも見えない）

---

# 設定済みの内容

`.streamlit/config.toml` で、Streamlitが同じPC以外からの接続も受け付けるように
設定済み（`server.address = "0.0.0.0"`）。`株探し起動.bat`はこれまで通り実行するだけでよい。

---

# 初回セットアップ手順

## 1. Tailscaleのインストール・サインイン

- PC（このダッシュボードを起動する端末）: https://tailscale.com/download/windows
  からインストールし、Google/Microsoftアカウント等でサインイン
- スマホ・他のPC: 各OSのTailscaleアプリをインストールし、**PCと同じアカウントで
  サインイン**

## 2. PCのTailscale IPを確認

PCでTailscaleアプリのメニュー、またはコマンドプロンプトで確認する。

```
tailscale ip -4
```

`100.x.x.x` の形式のIPアドレスが表示される（PC側で1回確認すればよい。以後は
基本的に変わらない）。

## 3. Windowsファイアウォールの許可

Tailscale経由の接続は初回、Windowsファイアウォールにブロックされることがある。
初めて他端末から接続してブロックされた場合は、Windowsのセキュリティ通知で
「プライベートネットワーク」への許可を許可する（パブリックネットワークへの
許可は不要）。通知が出ない場合は「Windows Defender ファイアウォール」の
詳細設定から、TCP 8501番ポートの受信を許可するルールを追加する。

## 4. 接続確認

PC側で `株探し起動.bat` を実行してダッシュボードを起動した状態で、
スマホ・他PCのブラウザから

```
http://<PCのTailscale IP>:8501
```

（例: `http://100.64.12.3:8501`）へアクセスする。

# スマホでの操作に関する既知の制限

- チャートの横スクロール（`docs/specifications/dashboard_spec.md` 4.2節）のうち、
  出来高チャート下の**独自スクロールバーのつまみドラッグ**はマウスイベント
  （`mousedown`/`mousemove`）のみに対応しており、タッチ操作には未対応
  （`ui/chart.py`）。
- 代わりに、**チャート本体を指で直接ドラッグしてパンする操作**はPlotly標準の
  タッチ操作でそのまま動作する。表示期間・表示幅のプルダウン操作も通常通り
  使える
- 矢印キーでの1本ずつ移動はスマホに物理キーボードが無い限り使えない
- スマホでのチャート操作を本格的に改善する場合は、独自スクロールバーへの
  タッチイベント対応（`touchstart`/`touchmove`/`touchend`）が別途必要
